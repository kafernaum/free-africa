# Free Africa

Une skill pour Claude dédiée à l’investigation documentaire sur les leviers du développement des pays africains : recherches sourcées, analyse critique et plans d’action évaluables.

## Objectif
Rechercher les obstacles, opportunités et solutions documentées ; confronter les explications ; comparer les options ; proposer des actions adaptées aux territoires et populations concernés. Ne pas traiter l’Afrique comme un ensemble homogène.

## Installation dans Claude
1. Télécharger ou cloner ce dépôt.
2. Créer un dossier nommé `free-africa` contenant `SKILL.md`, `references/` et `assets/`.
3. Compresser ce dossier en ZIP en conservant le dossier racine `free-africa/`.
4. Dans Claude, ouvrir Customize > Skills > + > Create skill > Upload a skill, selon les options disponibles dans votre interface.
5. Importer l’archive, activer la skill et lancer les tests.

## Exemple
> Utilise Free Africa pour étudier les leviers d’emploi productif des jeunes en Mauritanie. Délimite la question, sélectionne deux secteurs sur preuves, cite les sources et les périodes des données. Compare les options et propose un pilote avec coûts documentés ou à chiffrer, responsables pressentis, risques et indicateurs. Ne suppose aucun financement acquis.

## Contenu
- `SKILL.md` : instructions principales.
- `references/` : protocole, domaines et évaluation.
- `assets/modele-rapport.md` : modèle de dossier.
- `tests/tests-reception.md` : vérifications de qualité et de sécurité.
- `GUIDE.md` : utilisation et maintenance.

## Limites
La skill ne crée pas d’accès web, de connecteur, d’abonnement, de mémoire persistante ni de veille programmée. Elle utilise uniquement les capacités réellement disponibles dans Claude. Elle ne garantit ni exhaustivité ni absence d’erreur. Les conclusions importantes demandent une validation humaine.
