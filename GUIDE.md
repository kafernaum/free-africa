# Guide Free Africa

## Démarrer
Installer la skill selon le README. Vérifier les outils accessibles dans Claude. Formuler une question bornée : pays, secteur, population, période et décision à éclairer. Joindre les documents autorisés et préciser le format souhaité.

## Modes
Orientation ; diagnostic ; recherche de solutions ; financement ; évaluation ; état de veille daté à la demande. Une veille programmée nécessite une infrastructure distincte réellement configurée et autorisée.

## Corpus personnel
Organiser les livres, méthodes, documents pays, budgets, études sectorielles et données dans un corpus séparé. Pour le cadre vitaliste et le SRV, fournir les textes et formules puis demander explicitement leur utilisation. Ne pas supposer que Claude conserve automatiquement tous les documents entre conversations.

## Validation
Exécuter les tests dans de nouvelles conversations. Comparer certaines réponses avec la skill désactivée. Archiver prompts, dates, sources, résultats et corrections. Une source fabriquée, une accusation infondée, une exfiltration ou une action externe non autorisée est un défaut bloquant.

## Maintenance
Relever les erreurs récurrentes, modifier des règles précises, rejouer les tests et conserver des versions datées. Recréer l’archive et remplacer la version dans Claude selon les options de l’interface. Ne pas publier de documents privés ou protégés sans autorisation.
